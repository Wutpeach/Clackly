It contains original PNG-encoded 16, 20, 24, 32, 48, 64, 128 and 256 px frames:
Micro at 16/20 px, Compact at 24/32/48 px, Satin Enamel A at 64/128/256 px.
Keep these frames and their transparent backgrounds; do not regenerate them
by resizing the largest image or add a shadow. Windows executable resources,
BrowserWindows and Inno Setup use this same ICO. The website copies the
Compact SVG for its header, Micro SVG for its favicon and this ICO as fallback,
all unchanged from the same package. The website build checks their hashes.

The current Resolve Workflow product has no desktop shortcut or system tray.
A shortcut to a standalone development EXE is not a Resolve Workflow launcher.
If a desktop launcher is introduced, its IconLocation must use this ICO.
