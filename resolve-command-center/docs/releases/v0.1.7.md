# Clackly v0.1.7 — Windows x64

本次为品牌图标更新，应用功能沿用 v0.1.6。

- Windows 应用窗口、EXE、安装器及卸载入口统一使用新的 **Satin Enamel A** 图标；保留针对小尺寸设计的 Micro / Compact 图形。
- 随包 Developer Skill 的说明已校正，明确 Command UI、Dynamic Prepare 和 Extension Views 等能力从 v0.1.6 起公开提供。
- 中英文产品首页与文档站同步新图标，文档新访客默认使用深色主题，并保留手动主题选择。

## 安装与升级

下载 **Clackly-Setup-0.1.7-win-x64.exe**。v0.1.5 / v0.1.6 用户也可在 Settings 检查更新、下载并校验后，主动启动安装；v0.1.3 及更早版本请手动下载安装 EXE。保存工作，并按提示自行关闭 Resolve；覆盖升级保留用户配置和偏好。

安装器包含完整应用、界面和受管 Python Runtime。`WorkflowIntegration.node` 仍仅从用户本机官方 Resolve 安装中验证并复制，不随包分发。

安装器沿用未签名发行方式，Windows 可能显示 SmartScreen 或“未知发布者”提示。请核对官方来源与本 Release 的 SHA-256，无需关闭 Windows 安全功能。第三方扩展会在本机执行代码，请仅安装可信扩展。

发布新版不会自动替换当前安装。正式构建验证与实际安装验收分别记录；本次不额外宣称完成断网安装、标准用户 UAC 或完整卸载实测。
