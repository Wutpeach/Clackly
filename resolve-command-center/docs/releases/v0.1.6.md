# Clackly v0.1.6 — Windows x64

本版集中更新第三方扩展体验、命令发现与开发工具，包含自 v0.1.5 以来的改进。

## 第三方扩展

- 支持从 Settings 安装和管理本地 `.clackly` 扩展包，包括配置、启用/禁用、更新和卸载；命令无需重启即可刷新。
- Extension Commands 支持运行前的输入表单、确认提示，以及运行状态、结果和错误反馈。
- 支持运行前从当前项目读取动态选项，供表单选择与确认后执行。
- 新增独立的 Extension Views，支持列表与详情、上下文操作、表单编辑和批量操作；视图重新获得焦点时可刷新内容。
- 扩展 Python 缓存移至包外受管目录，兼顾重复运行与扩展包完整性校验。

## Launcher 与搜索

- 安装扩展后，其命令直接进入默认 Launcher；普通 Commands 中内置与扩展命令交错展示。
- 取消默认列表全局 9 条命令限制，沿用现有滚动列表，保持 240×320 窗口尺寸。
- 保留 Pinned / Recent / Commands 分组；Pin 和 Recent 在内置命令、扩展与普通 Resolve Scripts 之间统一持久化、排序和去重。普通脚本仍通过 Pin、Recent 或搜索发现。
- 同名命令继续显示来源，便于区分 Clackly、扩展名称与脚本来源；搜索保持相关性优先。
- 长列表的键盘导航按显示顺序移动并自动滚动；Pin/Unpin 后保持命令选中，卸载扩展后选中状态保持有效。

## Settings 与开发工具

- 简化常规设置与更新信息，统一保存/放弃更改操作，并在离开未保存配置前提示确认。
- 随应用提供 Clackly Developer Skill；Settings 可复制安装指令或打开 Skill 所在目录，便于接入支持 Agent Skills 的工具。
- Developer Skill 包含扩展协议参考、示例与打包工具，覆盖 Command UI、动态选项和 Extension Views。
- 改善首次安装时的共享目录权限兼容性。

## 安装与升级

1. 下载本 Release 的 **Clackly-Setup-0.1.6-win-x64.exe**，保存工作并按提示自行关闭 DaVinci Resolve，再运行安装器。正常覆盖升级保留用户配置和偏好。
2. v0.1.5 用户可通过 Settings 检查、下载并校验更新，再主动启动安装；v0.1.3 及更早版本用户需要先手动下载安装 EXE 一次。
3. 安装器内含应用、界面和受管 Python Runtime；`WorkflowIntegration.node` 仅从用户本机的官方 Resolve SamplePlugin 验证并复制，发行包不包含该文件。
4. 安装器沿用 **未签名**发行方式，Windows 可能显示 SmartScreen 或“未知发布者”提示。请核对官方来源与 Release 中的 SHA-256，无需关闭 Windows 安全功能。
5. 第三方扩展会在本机执行代码，请仅安装你信任的扩展。

发行验证与安装验收分别记录；发布新版不会自动替换当前 Workflow。实际断网安装、标准用户 UAC 和完整卸载尚未专项实测。
