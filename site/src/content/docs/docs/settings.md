从命令面板页脚打开 **Settings**。Settings 是独立窗口，可以在保留 Resolve 上下文的同时配置 Clackly。

## 通用设置

通用设置提供应用信息、语言与更新入口。界面支持 **English / 简体中文**。语言偏好与功能配置分开管理；切换语言后，面板和已打开的 Settings 使用当前语言。

## 功能与依赖

在侧栏选择功能，在详情区阅读描述、状态和所需设置。例如 AE 导出需要可用的 After Effects 及正确路径；并非所有命令安装后就一定可执行。根据界面提示补齐缺失配置，保存后再次检查状态。

编辑字段只修改当前草稿，点击 **保存** 才持久化；**放弃更改** 恢复未保存内容。带未保存更改离开时会提示确认。启用状态与是否具备运行条件是两回事：已启用的功能仍可能缺依赖或暂不可用。

## 扩展与开发工具

**扩展** 页负责安装、更新、启用/禁用、卸载扩展及其设置；还包含 **Clackly Developer Skill** 的“复制 Agent 安装提示词”和“打开 Skill 文件夹”。

应用升级更新随包 Skill 源目录，**不会自动更新 Agent 已导入的 Skill 副本**。详见 [Skill 安装](/Clackly/docs/developer/skill/) 和[升级](/Clackly/docs/updates/)。
