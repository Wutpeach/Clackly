## 呼出面板

先从 Resolve 的 **Workspace → Workflow Integrations → Clackly** 加载插件，再按 **Ctrl + Space**。面板默认隐藏，呼出后出现在鼠标附近，遇到屏幕边缘会限制在工作区内。

## 选择一个操作

1. 输入命令名称，例如 **Add Marker**，或使用当前界面语言对应的名称。
2. 用上下方向键选择，按 **Enter** 执行。执行前确认当前项目、时间线与目标正确。
3. 按 **Escape** 从搜索回到 Launcher；不用时关闭面板并回到 Resolve。

添加标记会修改时间线。初次尝试请使用可丢弃的本地测试项目；也可以先浏览命令、Settings 或只读扩展。

## 看清命令的行为

面板内的 Info 控件或 **Tab** 可查看选中命令的信息/交互映射。带修饰键的鼠标操作以实际显示的映射为准，不要从命令名称猜测行为。列表中的数字提示属于 Launcher 快速选择，不是 Resolve 全局快捷键。

首页展示的是实际 Clackly renderer 的浏览器截图，使用演示数据；它说明界面外观，不代表真实 Resolve 执行或系统原生窗口验收。
