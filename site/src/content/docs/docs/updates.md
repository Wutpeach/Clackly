## 从当前版本升级

v0.1.5 用户可在 **Settings → 通用设置** 检查更新、下载并校验，然后主动启动安装。Clackly 不会因发表新 Release 就自动替换当前 Workflow，也不会替你关闭或重启 Resolve。

v0.1.3 及更早版本需要先[手动下载 EXE](/Clackly/docs/install/)一次。也可以直接从官方 Release 下载新版安装器覆盖升级；正常流程保留配置与偏好。

## 升级前后

保存 Resolve 工作和 View 表单，按提示自行关闭 Resolve，再运行安装器。安装完成后重新启动 Resolve，从 Workflow Integrations 菜单重新加载 Clackly，检查版本和常用命令。

扩展包是独立版本，更新应用不等于更新所有扩展。Agent 的 Skill 副本也不会自动同步：到 Settings → 扩展重新复制安装提示词，经你确认更新。

若安装或恢复失败，保留界面的错误、版本和安装记录，先[排错](/Clackly/docs/troubleshooting/)。不要删除受管状态或用手动复制文件冒充恢复。
