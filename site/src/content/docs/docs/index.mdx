Clackly 是 DaVinci Resolve 内的轻量命令面板。按 **Ctrl + Space** 呼出，找到命令，执行后回到剪辑。

## 适用环境

这份文档以 **2026-11-08 公开发行的 v0.1.6** 为基准。下载、扩展、Command UI、动态 Prepare、Extension Views 和随包 Developer Skill 均已进入该发行版。已合并源码不自动等于已发行能力。

当前公开分发面向 **Windows x64 + DaVinci Resolve Studio Workflow Integration**。仓库记录的合格宿主基线是 Resolve 20.3.2.9；不同版本、免费版和其他系统的兼容性不能由这份文档保证。需要可用的 Resolve Scripting API，部分功能还依赖外部应用或配置。

Clackly 不是网页服务。这个网站用于介绍和查阅，桌面命令在你的本机执行。
