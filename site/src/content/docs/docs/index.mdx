Clackly 是 DaVinci Resolve 内的轻量命令面板。按 **Ctrl + Space** 呼出，找到命令，执行后回到剪辑。

## 适用环境

文档以 **v0.1.7（2026-11-09）** 为基准，功能变化见[发行历史](/Clackly/docs/releases/)。

公开版本面向 **Windows x64 + DaVinci Resolve Studio**，通过 Workflow Integration 运行，需要可用的 Resolve Scripting API。已验证的宿主基线为 **Resolve 20.3.2.9**；其他版本、免费版及其他系统的兼容性未保证。AE 导出等功能还需要对应的外部应用与配置。

命令在本机执行；扩展会运行本地代码，请只安装可信来源的包。
