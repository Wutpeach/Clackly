## Upgrade from your version

From v0.1.5 onward, check, download and verify updates in **Settings → General Settings**, then start installation yourself. The app does not install updates automatically or close and restart Resolve for you.

v0.1.3 and earlier need one [manual EXE download](/Clackly/en/docs/install/) first. You can also download the official newer installer directly; normal in-place upgrades retain configuration and preferences.

## Before and after

Save Resolve work and View forms, close Resolve yourself when prompted, then run the installer. Restart Resolve afterwards, load Clackly from Workflow Integrations, and check its version and familiar commands.

Application upgrades do not update extension packages or imported Agent Skill copies. Update packages in [Extensions](/Clackly/en/docs/extensions/) and reimport the Skill using its [installation guide](/Clackly/en/docs/developer/skill/).

If installation or recovery fails, keep the error, versions and installation record and follow [troubleshooting](/Clackly/en/docs/troubleshooting/). Do not delete managed state or replace files manually as a substitute for recovery.
