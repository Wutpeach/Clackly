[Official Release and installer](https://github.com/Wutpeach/Clackly/releases/tag/v0.1.7) · [Repository release notes](https://github.com/Wutpeach/Clackly/blob/v0.1.7/resolve-command-center/docs/releases/v0.1.7.md)

## v0.1.6 · 2026-11-08

[Official Release and installer](https://github.com/Wutpeach/Clackly/releases/tag/v0.1.6) · [Repository release notes](https://github.com/Wutpeach/Clackly/blob/v0.1.6/resolve-command-center/docs/releases/v0.1.6.md)

- Local extension installation, configuration, enable/disable, replace/update and removal.
- Command UI one-run forms, confirmation, results/errors and Dynamic Prepare live choices.
- Extension Views List/Detail, Create/Edit Forms, multiselect/batch and refocus refresh.
- Alternating built-in/extension Launcher entries without a global nine-item cutoff; persistent cross-source Pin/Recent.
- Settings Save/Discard and dirty-draft prompts; bundled Developer Skill and Agent installation guidance.
- Managed Python caches outside packages and improved first-install shared-directory compatibility.

Release source: **d883c97b3cf6cc4dd61757f762a73b28625ea2c2**. The [official Tag build](https://github.com/Wutpeach/Clackly/actions/runs/42477636440) and matching main verification succeeded. See this version's official Release for its installer digest.
