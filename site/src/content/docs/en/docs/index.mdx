## Supported context

These docs cover **v0.1.7 (2026-11-09)**. See [release history](/Clackly/en/docs/releases/) for capability changes.

The public release targets **Windows x64 + DaVinci Resolve Studio**, runs through Workflow Integration and needs a working Resolve Scripting API. The verified Host baseline is **Resolve 20.3.2.9**; other versions, the free edition and other systems are not guaranteed. Features such as AE export also need the corresponding external application and configuration.

Commands run locally. Extensions execute local code; install only packages you trust.
