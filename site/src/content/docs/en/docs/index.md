Clackly is a compact command palette inside DaVinci Resolve. Press **Ctrl + Space**, find a command, then return to your edit.

These docs describe **v0.1.6, publicly released on 2026-11-08**. Extensions, Command UI, Dynamic Prepare, Extension Views and the bundled Developer Skill ship in that release. A merged source change alone does not establish public availability.

## Supported context

Public distribution targets **Windows x64 + DaVinci Resolve Studio Workflow Integration**. The repository's qualified Host baseline is Resolve 20.3.2.9. This is not a guarantee for every Resolve version, the free edition or other operating systems. A working Resolve Scripting API is needed; some features also need external applications or configuration.

Clackly runs on your computer. This website is for learning and reference.
