Open **Settings** from the palette footer. It is a separate window for configuring Clackly while retaining your Resolve workspace.

## General settings

General Settings contains application information, language and update controls. The interface supports **English / 简体中文**. Language preferences are separate from feature configuration; the palette and open Settings use the selected language.

## Features and dependencies

Choose a feature in the sidebar and read its description, status and required settings. AE export, for example, needs a usable After Effects installation and correct path. Installed does not always mean runnable. Complete missing configuration, save and check readiness again.

Field edits remain a draft until **Save**. **Discard changes** restores unsaved values, and navigating away with a dirty draft prompts for confirmation. Enablement and readiness are separate: an enabled feature can still lack dependencies or be temporarily unavailable.

## Extensions and developer tools

**Extensions** manages packages, their configuration, enable/disable, updates and removal. It also includes **Clackly Developer Skill**, with **Copy Agent installation prompt** and **Open Skill folder**.

An application upgrade updates the bundled Skill source. **Imported Agent copies do not update automatically.** See [Skill installation](/Clackly/en/docs/developer/skill/) and [updates](/Clackly/en/docs/updates/).
