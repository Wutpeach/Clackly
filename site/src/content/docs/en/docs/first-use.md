## Open the palette

Load **Workspace → Workflow Integrations → Clackly** in Resolve, then press **Ctrl + Space**. The palette starts hidden, opens near the pointer and stays within the available work area.

## Choose an action

1. Type a command name, such as **Add Marker**, or its localized name.
2. Select with the arrow keys and press **Enter**. Verify the current project, timeline and intended target first.
3. Press **Escape** to leave search for the Launcher. Dismiss the palette to return to Resolve.

Adding a marker changes the timeline. Use a disposable local project for a first experiment, or start by browsing commands, Settings or a read-only extension.

## Understand the selected command

Use the Info control or **Tab** to inspect its description or interaction mappings. Follow the mappings actually shown for modifier-click actions. Launcher numbers are quick-selection hints, not global Resolve shortcuts.

The homepage image is a browser capture of the actual Clackly renderer using demonstration data. It shows the interface, not native window acceptance or real Resolve execution.
