# Clackly website

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

DaVinci Resolve editors evaluating Clackly, and extension authors using an AI Agent.

## Product Purpose

Introduce the keyboard-first command palette, lead visitors to the official Windows release, and connect them to localized documentation and Build with AI.

## Capabilities and Constraints

The public baseline is v0.1.6, Windows x64, Resolve Studio Workflow Integration. Launcher searches commands, trusted extensions and ordinary scripts; Pinned and Recent keep commands accessible. Extensions can use host-rendered forms and persistent list/detail/form views. The official Developer Skill defines extension authoring. Installation is unsigned; extensions execute local code.

## Brand Commitments

Preserve the approved R1 icon, Clackly name and licensed HarmonyOS Sans. Issue #14 requests Raycast's clarity, visual hierarchy and product presentation as references, without copying its artwork or brand. Homepage changes stay inside site/; documentation and the app retain their own interfaces.

## Evidence on Hand

The real application renderer can be captured headlessly with deterministic demonstration data. These captures do not establish native Resolve execution. Timeline scenery must be identified as a schematic. No testimonials, performance benchmarks or unreleased capabilities are available as proof.

## Accessibility & Inclusion

Chinese and English have equal coverage. Support 1440px desktop and 320/390px phones, keyboard navigation, readable contrast and reduced motion. Visual acceptance precedes merging or publishing.
